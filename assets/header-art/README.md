# Interior page header artwork

These PNG files are the master assets for the route-specific interior page
headers. `npm run images:optimize` exports WebP presentation files to
`public/header-art` and responsive variants to `public/optimized`.

The artwork was generated as a coordinated set for this website. The shared
direction was a premium mixed-media editorial illustration combining dark
forest-green screen print, aged-brass linework, restrained copper accents,
ivory highlights, fibrous paper grain, and industrial blueprint geometry. Each
16:9 composition reserves calm, dark space on the left for page headings and
places the main subject on the right. The prompts excluded words, numbers,
logos, labels, watermarks, borders, UI, and close-up people.

Subject prompts:

- `our-story.png`: early factory silhouette, survey contours, tree rings, tea
  leaves, and a heritage ledger motif.
- `estate-factory.png`: tea machinery, withering trays, gears, roof geometry,
  and solar panels.
- `teas.png`: loose black tea, a tea cup, rising steam, and abstract package
  silhouettes.
- `sustainability.png`: tea terraces, roots and soil, water stewardship, and
  solar energy.
- `quality.png`: tea tasting, leaf inspection, calibration geometry, and an
  abstract assurance seal.
- `trade.png`: timber tea chests, route arcs, cargo geometry, and a brass
  weighing scale.
- `visit.png`: a path through tea terraces and tropical planting toward a tea
  factory pavilion.
- `contact.png`: tea leaves and a cup with abstract envelope, telephone, and
  location motifs.
